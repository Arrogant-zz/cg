# Оспаривание операции по карте

Когда применять: клиент не узнаёт списание по карте и просит разобраться.

## Процедура
1. Получить информацию о картах клиента.
2. Получить этапы экспертизы.
3. Выставить экспертизу по оспариванию операции.
4. Ответить клиенту: «Мы передали операцию на проверку.»
5. Отложить кейс до выполнения экспертиз.
