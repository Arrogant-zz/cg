# Смена канала уведомлений

Когда применять: клиент просит присылать уведомления по обращению в другой канал.

## Процедура
1. Получить каналы уведомлений по кейсу.
2. Получить уведомления клиента за период.
3. Сменить канал уведомлений на SMS.
4. Ответить клиенту: «Уведомления по обращению будут приходить в SMS.»
5. Закрыть кейс с ответом.
