# Блокировка после неверного PIN

Когда применять: клиент сообщает, что карта перестала работать после нескольких неверных вводов PIN.

## Процедура
1. Проверить статус карты.
2. Разблокировать карту.
3. Ответить клиенту: «Ваша карта разблокирована, можно пользоваться ею как обычно.»
4. Закрыть обращение.
