# Перевыпуск карты

Когда применять: клиент потерял карту или она повреждена.

## Процедура
1. Проверить статус карты.
2. Перевыпустить карту.
3. Ответить клиенту: «Карта будет перевыпущена, мы сообщим о готовности.»
4. Закрыть обращение.
