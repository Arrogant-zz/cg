## Образ

«Тихая лаборатория»: белый лист на известковом фоне, графитовый текст и один оранжевый акцент. Цвет появляется только там, где он что-то значит. Блоки разделяют воздух и линии 1 px; тени не используются, кроме кольца фокуса.

Принципы:

1. **Цвет — только для смысла.** Интерфейс графитовый. Оранжевый — знак, ход в реальном времени и обучение.
2. **Агент отдельно от стенда.** Красный — только неуспех агента. Сбои LLM-оператора, судьи, служебных команд и стенда — фиолетовые.
3. **Нет данных — не ноль.** Пропуск показывается пунктиром и причиной, а не нулём, ложным успехом или неуспехом.
4. **Скрытое видно.** Инструкция и решения оператора, разметка поправок и оценка помечены пунктиром и знаком «скрыто от агента».

## Ритм и форма

- Шаг отступов: 4, 8, 12, 16, 24, 32, 48.
- Радиусы: 7 — метки и версии, 12 — кнопки и поля, 16 — карточки, 18 — лист, 999 — статусы.
- Цели нажатия — от 44 px.
- Раскладка: меню слева на известковом фоне, белый лист справа. На ширине телефона меню становится горизонтальной лентой над листом, таблицы прокручиваются в своей рамке.
- Иконки: линия 1,6 на сетке 24, размеры 14, 16 и 18, цвет текста. Эмодзи не используются.

## Компоненты

| Группа | Состав |
| --- | --- |
| Управление | Кнопки: основная графитовая, вторичная, тихая, остановка, недоступная, кнопка-иконка. Поле, поиск, выбор из списка, заблокированный выбор, сегменты, переключатель, флажок, карточка выбора |
| Тип корзины | «Обучающая» — оранжевый мяч из знака, «Проверяющая» — пустое кольцо |
| Статусы | Состояния прогона, итог кейса, технические статусы, отметки проверок, полоса результатов корзины |
| Метрики | Плитка с верхней графитовой линией и знаменателем; пунктир для «нет данных»; сравнение «было → стало» |
| Ссылки | Файл, идентификатор, урок, версии: исходная — контуром, полученная — заливкой, рабочая копия — пунктиром |
| Настройки | Ошибка с файлом, полем, причиной и действием; строки проверок |
| Прогон | План команд /reset → кейс → /case-capture → /skill-curator; шаги кейса; подготовка набора скиллов |
| Диалог | Сообщения агента, LLM-оператора, человека, стартовое сообщение ClawGym, служебная команда через ленту |
| Инструмент | Ответ заглушки, ошибка, нет заглушки, ответ человека, подтверждение с обратным отсчётом и его исходы |
| Оценка | Итог, проверки действий с событиями-доказательствами, LLM-оценка по критериям, блоки «скрыто от агента» |
| Скиллы | Происхождение версий, изменения по проходам curator, контроль неизменности в проверке |

Классы компонентов собраны в [`clawgym.css`](clawgym.css) — тот же файл подключён ко всем экранам канваса.

## Что в дизайне — предложение

Эти правила показаны на экранах, но владелец их ещё не утверждал:

- отдельный выбор модели оценки;
- итоговый успех — все обязательные проверки действий и ответа пройдены;
- финальный проход curator для неполной пачки;
- после технического сбоя кейса capture не отправляется, а кейс не входит в счётчик curator;
- в проверяющей корзине обучающие поправки из инструкции решения не исполняются, расхождение отмечается;
- при отсутствии заглушки в автоматическом прогоне агент получает ошибку инструмента;
- при нескольких подходящих заглушках выбирается заглушка с более точным условием;
- красный — только неуспех агента, сбои стенда — фиолетовые.
