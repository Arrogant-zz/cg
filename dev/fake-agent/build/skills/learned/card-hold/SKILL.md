# Заблокированная сумма по карте

Когда применять: клиент видит по карте заблокированную, но не списанную сумму и просит разобраться.

## Процедура
1. Посмотреть историю операций по карте за период операции.
2. Получить этапы экспертизы.
3. Выставить экспертизу по оспариванию операции.
4. Отложить кейс до выполнения экспертиз.
