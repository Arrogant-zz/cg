# Действия после закрытия

Когда применять: только в тестах ClawGym. Скилл проверяет терминальные инструменты — после закрытия агент в том же ходе читает историю, пишет заметку и пытается отложить кейс.

## Процедура
1. Ответить клиенту: «Ваше обращение решено.»
2. Закрыть кейс с ответом.
3. Проверить историю решения кейса.
4. Добавить заметку на кейс.
5. Отложить кейс до ответа клиента.
