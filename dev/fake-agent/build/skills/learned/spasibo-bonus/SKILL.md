# Бонусы СберСпасибо не начислены

Когда применять: клиент сообщает, что за покупку не пришли бонусы СберСпасибо.

## Процедура
1. Запросить основную информацию Спасибо по клиенту.
2. Ответить клиенту: «Бонусы начисляются автоматически после покупки.»
3. Закрыть кейс с ответом.
